# Sekvensielle skalaer

Ordnede data, lav → høy. Se [velge-type.md](velge-type.md) for når denne familien passer.

HEX-verdier hentet direkte fra kildenes egne datasett. «CVD-trygg» betyr at kilden selv merker skalaen som fargeblind-sikker; mangler merket er skalaen bare ikke eksplisitt testet. Se [tilgjengelighet.md](tilgjengelighet.md).
