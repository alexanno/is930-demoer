Modul 0: Introduksjon og praktisk informasjon

Velkommen til IS-930 Introduksjon til Geografisk IT og Kunstig Intelligens! Denne modulen hjelper deg å komme i gang før første samling. Her får du oversikt over hvordan kurset er lagt opp, hvilke verktøy og kontoer du bør ha på plass, og hvor du kan presentere deg selv for de andre deltakerne.

Kurset er heldigitalt. Samlinger, webinar og veiledning holdes i Zoom, og all dialog utenom samlingene foregår fortrinnsvis i diskusjonsforumet i Canvas. Vi starter med et digitalt introduksjonswebinar tirsdag 6. oktober kl. 09:00–11:00. Zoom-lenken finner du i semesterplanen på forsiden.

Etter denne modulen har du

  • presentert deg selv i diskusjonsforumet
  • fått oversikt over hvordan kurset er organisert i Canvas og Zoom
  • installert og testet verktøyene du trenger til samlingene (Zoom, QGIS og Google-konto)
  • valgt om du vil sette opp utviklerverktøy for å prøve ut stoffet i praksis

1. Presenter deg selv og bli kjent

Siden kurset er heldigitalt, er diskusjonsforumet stedet der vi blir kjent. Presenter deg i forumet før første samling, gjerne med:

  • navn, hvor du jobber og hvilken rolle du har
  • din erfaring med kart, GIS eller KI (ingen forkunnskaper er påkrevd)
  • hva du håper å få ut av kurset

3. Verktøy og kontoer alle bør ha

Dette er det du trenger for å følge samlingene og gjennomføre oppgavene. Alt er gratis, bortsett fra Claude Pro som er anbefalt, men ikke påkrevd. Prøv å ha alt på plass før samling 1 (22. oktober).

Verktøy Hva brukes det til? Slik kommer du i gang
Zoom Webinar, samlinger og veiledning Last ned fra zoom.us/download, og test mikrofon og kamera. [Eventuelt: logg inn med UiA-konto.]
QGIS Gratis GIS-program for kartdata og romlig analyse

Windows: installer via QGIS w/ OSGeo4W (velg «Express install» og QGIS).
Mac: installer via QGIS
Mac-brukere må /bør også installere GDAL med Homebrew:
brew install gdal
Google-konto Tilgang til Google Colab (Python i nettleseren, uten installasjon) Logg inn på colab.research.google.com med en personlig Google-konto, og sjekk at du kan opprette en ny notebook.
Claude Pro
Anbefalt		 KI-assistent som vi bruker aktivt i undervisningen Claude er ikke et absolutt krav, men anbefalt for best utbytte av kurset. Foreleser kommer til å bruke Claude Pro for demonstrasjoner. Alternativer og gratisversjoner av KI-agenter vil fungere til en viss grad. Opprett konto på claude.ai. Last ned og installer desktop-applikasjonen. 

4. Utviklerverktøy (valgfritt)

Vil du prøve ut det vi lærer i praksis, med egen kode, webkart og KI-verktøy på din egen maskin? Da kan du sette opp verktøyene under. Dette er ikke et krav for å bestå emnet, og du kan vente med det til du ser behovet.

Verktøy Hva brukes det til? Slik kommer du i gang
VS Code Kodeeditor for Python, JavaScript og HTML Last ned fra code.visualstudio.com.
Claude i VS Code / Claude Code (CLI) KI-assistent som skriver og forklarer kode direkte i prosjektet ditt Installer Claude-utvidelsen fra VS Code Marketplace, eller CLI-en (krever Node.js):
npm install -g @anthropic-ai/claude-code
Krever Claude-abonnement eller API-tilgang.
Node.js Runtime for javascript og cli'er, bl.a. Claude Code Last ned LTS-versjonen fra nodejs.org. Sjekk med node --version.
uv
Python-håndtering		 Installerer Python og pakker, og oppretter prosjekter raskt Mac/Linux:
curl -LsSf https://astral.sh/uv/install.sh | sh
Windows (PowerShell):
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Se docs.astral.sh/uv.
Cloudflare-konto Publisering av webkart og enkle tjenester i skyen Opprett gratis konto på dash.cloudflare.com/sign-up.
