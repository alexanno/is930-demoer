API-standarder

Geografiske data deles stadig oftere som tjenester på nett i stedet for som filer. API-standarder gjør at ulike klienter, som QGIS, nettkart og Python-skript, kan hente data fra ulike servere på samme måte. Her får du en rask oversikt over de vanligste standardene og praksisene, med fokus på når du bruker hva.

Innhold

Hva trenger du?

  • Vise et kart: kartbilder (WMS, OGC API Maps) eller tiles (WMTS, XYZ, OGC API Tiles).
  • Hente selve dataene: vektorobjekter med attributter (WFS, OGC API Features) eller rasterdata (WCS, OGC API Coverages).
  • Finne data: kataloger og metadata (CSW, OGC API Records, STAC).
  • Kjøre analyser på serveren: prosesseringstjenester (OGC API Processes).

OGC-standarder: de klassiske og mest brukte

Disse har vært i bruk i mange år, og du finner dem hos de fleste offentlige dataeiere. Oversikten er ikke uttømmende.

Standard Hva gir den deg? Bruk når Mer info
WMS
Web Map Service		 Ferdige kartbilder (for eksempel PNG eller JPEG) for et utsnitt. Du kan også spørre om informasjon om et objekt med GetFeatureInfo. Du bare skal vise et kartlag, for eksempel et temakart eller en fagdatabase, og ikke trenger selve dataene. OGC: WMS
WMTS
Web Map Tile Service		 Forhåndslagde kartfliser (tiles) i faste målestokknivåer. Bakgrunnskart og andre lag mange skal bruke raskt. Geonorge tilbyr for eksempel Topografisk Norgeskart som WMTS. OGC: WMTS
WFS
Web Feature Service		 Selve vektorobjektene med geometri og attributter, for eksempel som GML. Du vil gjøre analyser, filtrere eller lage din egen visualisering. Statens vegvesen og Geonorge tilbyr data som WFS. OGC: WFS
WCS
Web Coverage Service		 Selve rasterdataene (coverages), med mulighet for å hente ut deler av dem. Du trenger rå rasterverdier, for eksempel høydedata, og ikke bare et bilde. OGC: WCS
CSW
Catalogue Service for the Web		 Søk i metadatakataloger. Du skal finne ut hvilke datasett og tjenester som finnes. OGC: CSW

Tjenestene spørres med URL-parametere, for eksempel ?service=WMS&request=GetCapabilities, som returnerer en beskrivelse av hva tjenesten tilbyr. Geonorge tilbyr i tillegg nedlasting via Atom-feed, som ikke er en OGC-standard. Du finner tjenestene i Geonorges kartkatalog.

Nyere OGC API-standarder

OGC API-ene er moderne etterfølgere til de klassiske tjenestene. De bruker REST, JSON og OpenAPI, og er bygget opp av gjenbrukbare byggeklosser.

Standard Etterfølger til Hva gir den deg? Bruk når
OGC API - Features WFS Vektorobjekter som GeoJSON via enkle URL-er, for eksempel /collections/lag/items. Du skal hente vektordata til web-apper eller skript, og vil ha et enkelt, moderne grensesnitt.
OGC API - Tiles WMTS Alle typer tiles: vektortiler, karttiles og coverage-tiles. Du skal levere eller bruke tiler, særlig vektortiler.
OGC API - Maps WMS Kartbilder og rasterinnhold. Du vil ha ferdig tegnede kart fra et moderne API.
OGC API - Coverages WCS Rasterdata, for eksempel som GeoTIFF. Du trenger rasterverdier eller utsnitt av dem.
OGC API - Processes WPS Prosesseringsverktøy som kan kalles og kombineres via API. Du vil kjøre analyser på serveren i stedet for lokalt.
OGC API - Records CSW Søk og tilgang til metadata om geografiske ressurser. Du skal bygge eller bruke et søkbart datakatalog.
OGC API - EDR
Environmental Data Retrieval		 (ny) Definerte spørringsmønstre for miljødata, for eksempel posisjon eller område. Du skal hente ut miljø- og værdata for en posisjon eller et område.

Oversikt og status for hver standard finner du på ogcapi.ogc.org.

De-facto-standarder

Disse er ikke formelt standardisert av OGC, men har blitt standard gjennom bred bruk.

Praksis Hva er det? Bruk når Mer info
XYZ-tiles / TMS Enkle URL-maler for kartfliser, for eksempel /{z}/{x}/{y}.png. Bakgrunnskart i nettkart som Leaflet, OpenLayers og MapLibre. Enkelt å sette opp og bruke. OSM: Slippy map tilenames
TileJSON En enkel JSON-beskrivelse av et tilesett. Du skal peke en kartklient til et tilesett og trenger metadata om det. TileJSON-spesifikasjonen
Mapbox Vector Tiles (MVT) Det mest brukte formatet for vektortiler. Du vil ha raske, stilbare vektorkart i nettleseren. MVT-spesifikasjonen
ArcGIS REST API Esris REST-grensesnitt for kart- og objekttjenester. Dataene ligger i ArcGIS Online eller ArcGIS Enterprise, eller du skal integrere med Esri-produkter. ArcGIS REST API
STAC
SpatioTemporal Asset Catalog		 Felles måte å katalogisere satellitt- og jordobservasjonsdata på. Du skal finne og hente satellittbilder og andre rasterdata fra katalog. Mer om dette i neste tema. stacspec.org

Aktivitet

Forslag til øvelser du kan prøve på egenhånd:

  • Åpne https://wms.geonorge.no/skwms1/wms.norges_grunnkart?service=wms&request=getcapabilities i nettleseren og se hva en GetCapabilities-respons inneholder. Legg deretter tjenesten til som WMS-lag i QGIS.
  • Legg Statens vegvesens WFS (https://ogckart-sn1.atlas.vegvesen.no/wfs?service=wfs&version=1.1.0&request=GetCapabilities) til i QGIS. Hva kan du gjøre med WFS-lagene som du ikke kan med et WMS-lag?
  • Velg tre scenarier (bakgrunnskart i en nettapp, analyse av vegdata, søk etter satellittbilder) og begrunn hvilken standard du ville brukt.
  • For viderekomne: hent data fra en WFS med Python og OWSLib, for eksempel med uv run --with owslib python.
