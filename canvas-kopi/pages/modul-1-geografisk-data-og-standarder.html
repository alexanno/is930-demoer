Modul 1: Geografisk data og standarder

Denne siden er det faglige underlaget for Samling 1 – Introduksjon til geografisk IT torsdag 22. oktober kl. 09:00–13:00. Her finner du agenda, læringsmål og en oversikt over temaene vi tar for oss, med lenker til utdypende temasider og eksterne eksempler. Se gjennom siden før samlingen, og bruk den som oppslagsverk etterpå.

Vi starter med noe konkret: hvorfor geografiske data er interessante, og hva som skjer når ulike kilder viser samme sted ulikt. Deretter går vi inn i begrepene og standardene som forklarer hvorfor.

Etter denne modulen kan du

  • forklare hvorfor geografiske data kan gi rask innsikt, og hvordan visualisering bidrar til det
  • beskrive grunnbegreper som koordinatsystemer, projeksjoner, geometrityper og forskjellen på vektor- og rasterdata
  • velge en egnet visualiseringsmetode (dot map, choropleth, skalerte sirkler, heatmap) og fargeskala for et gitt datasett
  • skille mellom vanlige lagringsformater (GeoJSON, Shapefile, SOSI, GeoPackage, File Geodatabase) og vite når de passer
  • forklare hva API-standarder er, og skille mellom OGC-standarder og de-facto-standarder
  • finne og vurdere åpne datakilder som GeoNorge, OpenStreetMap og Overture Maps
  • vurdere hva KI-agenter kan og ikke kan gjøre med geodata, og hvordan du får bedre resultater
